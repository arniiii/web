# Демонстрация через этот компьютер

Приложение запущено без срока автоматического отключения. Работой управляет пользовательский systemd, поэтому закрытие чата и терминала не завершает сервер. Службы включены в автозапуск и перезапускаются при аварийном завершении. Для работы пользовательских служб после выхода из сеанса включён linger пользователя arnold.

## Ссылка и управление

Из корня проекта:

```bash
npm run demo:status
npm run demo:stop
npm run demo:start
```

`demo:status` показывает состояние трёх служб и текущий URL. Адрес также находится в `.local/hosting/url.txt`. `demo:stop` отключает автозапуск и останавливает туннель, приложение и PostgreSQL, сохраняя данные. `demo:start` снова включает фоновые службы.

Публичный учебный аккаунт: `demo@semester.app`, пароль `Semester2026!`. Преподаватель также может зарегистрировать отдельный аккаунт и проверить изоляцию данных.

## Устройство запуска

- `semester-demo-db.service` запускает PostgreSQL с прежним каталогом `.local/postgres` и проверяет готовность SQL-запросом.
- `semester-demo-app.service` применяет миграции, запускает FastAPI без режима разработки и отдаёт готовый клиент из `frontend/dist` на `127.0.0.1:8080`.
- `semester-demo-tunnel.service` открывает внешний HTTPS-адрес через Cloudflare Quick Tunnel. База и служебные метрики остаются на loopback.
- `semester-demo.target` объединяет службы и включён в пользовательский `default.target`.

React и API доступны по одному адресу. Прямой переход на `/subjects/1` возвращает приложение, а отсутствующий `/api/...` сохраняет 404. Исходники, `.env` и каталог PostgreSQL не раздаются как статические файлы.

Файлы служб находятся в `~/.config/systemd/user/`. Их установка воспроизводится командой `npm run demo:install` после обычной настройки проекта, сборки клиента и установки `cloudflared` в `.local/bin/cloudflared`. Бинарный файл взят из официального релиза Cloudflare 2026.10.7; его SHA256 при установке проверена по метаданным релиза. Бинарный файл и текущая ссылка исключены из Git вместе с `.local`.

## Журналы

```bash
journalctl --user -u semester-demo-app.service -n 50 --no-pager
journalctl --user -u semester-demo-db.service -n 50 --no-pager
journalctl --user -u semester-demo-tunnel.service -n 50 --no-pager
```

После изменения серверного кода:

```bash
systemctl --user restart semester-demo-app.service
```

После изменения интерфейса сначала выполните `npm run build`. Перезапускать туннель для обновления интерфейса не требуется.

## Доступность

Компьютер должен оставаться включённым и подключённым к интернету. Текущие настройки питания не менялись: системное действие при простое — `ignore`; установить отдельный sleep-inhibitor от этого пользователя система не разрешила.

Туннель временный: Cloudflare не гарантирует непрерывную доступность Quick Tunnels. При разрыве сети процесс пытается переподключиться. Если сам процесс туннеля или компьютер перезапускается, адрес может измениться; актуальный адрес обновляется в `.local/hosting/url.txt`. Для постоянного имени потребуется отдельный настроенный туннель с доменом.

Документация провайдера: [Cloudflare Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/).
