# Соответствие требованиям очной формы

Тема: приложение для планирования учебного семестра. Основание — [требования преподавателя](https://github.com/alkselsv-edu/tstu-courses/blob/main/assets/course-work-requirements.md). Требования заочной формы к этому проекту не применяются.

| Критерий | Реализация | Где проверить |
| --- | --- | --- |
| Запуск | Раздельный локальный запуск API, клиента и PostgreSQL | README, `/api/health` |
| Три связанные сущности | Пользователь → дисциплины → задания | Карточка дисциплины и задания, API, FK в миграции |
| CRUD двух сущностей | Дисциплины и задания | Страницы списков, карточек и форм |
| Поиск и фильтрация | Поиск названий; статус, дисциплина, приоритет и даты | `/subjects`, `/tasks`, query-параметры API |
| JWT | Регистрация, вход, Bearer, срок действия | `auth/`, `core/dependencies.py`, `shared/api.ts` |
| Чужие данные защищены | Владелец проверяется до чтения и изменения, включая перенос задания | `test_ownership_on_all_operations` |
| Хеширование и миграции | Argon2id; Alembic создаёт таблицы и ограничения | `core/security.py`, `alembic/versions/0001_initial.py` |
| Три и более страницы, загрузка и ошибки | Обзор, дисциплины, задания, профиль, вход, регистрация; общие состояния | React Router, `shared/ui.tsx` |
| Разрешённый стек | React + Redux Toolkit + FastAPI + SQLAlchemy + PostgreSQL | lock-файлы и исходный код |

## Дополнительные обязательные условия

- Формы управляются React и проверяются до отправки; сервер повторно валидирует данные через Pydantic.
- Данные предметной области не хранятся в `localStorage` и не ограничиваются памятью процесса.
- Пароль, хеш и тело невалидного запроса не возвращаются клиенту.
- Все HTTP-запросы клиента сосредоточены в одном модуле RTK Query.
- На сервере типизированы схемы, модели и основные зависимости; код разделён на модули предметной области.
- Секретный ключ формируется при настройке, находится в игнорируемом `.env`; пример настроек включён в Git.
